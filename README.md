# Echoes of the Estate

Narrative merge-and-mystery game. Vanilla HTML5 PWA, no build step, no backend.

- Play: https://bodhinath.github.io/echoes-of-the-estate/ (or open `index.html` locally).
- Design spec: `docs/DESIGN.md`.
- Google Play: wrap with Bubblewrap as a Trusted Web Activity (see `docs/PLAY.md`).

Standalone project. Not affiliated with any other product.
